Hari ini kamu membuat website satu halaman untuk sebuah usaha UMKM dengan bantuan AI. Hasilnya disimpan di GitHub dan ditayangkan di Vercel. Semua langkah memakai aplikasi biasa, tanpa mengetik perintah. Centang setiap langkah yang selesai, progresnya tersimpan di browser ini.

Sebelum datang

Malam sebelumnya, sekitar 30 menit
Kerjakan bagian ini sebelum hari workshop

Memasang aplikasi butuh unduhan yang cukup besar. Kalau ditunda ke hari H, waktu di kelas habis untuk instalasi.

Pilih alat AI kamu

Alat AI adalah aplikasi yang menulis kode atas perintahmu. Pilih satu, petunjuk di panduan ini ikut berubah. Tombol yang sama ada di kanan bawah.

Freebuff Desktop gratis, tanpa API key dan tanpa kartu kredit. Biayanya ditutup iklan teks.

OpenCode Desktop bersifat open source dan menyediakan model gratis bawaan. Model gratis bisa dibatasi atau berganti sewaktu-waktu, dan kadang lebih lambat di jam ramai.

Komputermu terdeteksi otomatis. Kalau salah, ganti Windows atau Mac di kanan bawah.

0.1Buat akun GitHub

Langkah

Buka github.com/signup, daftar, lalu verifikasi emailmu.

Berhasil kalau

Kamu bisa membuka github.com dalam keadaan login.

0.2Buat akun Vercel

Langkah

Buka vercel.com/signup dan pilih Continue with GitHub. Dengan begitu Vercel langsung terhubung ke repo kamu.

Berhasil kalau

Dashboard Vercel terbuka.

0.3Pasang GitHub Desktop dan login

Langkah

Unduh dari desktop.github.com dan pasang seperti aplikasi biasa. Buka aplikasinya, pilih Sign in to GitHub.com, lalu izinkan akses di browser.

Berhasil kalau

GitHub Desktop terbuka dan sudah menampilkan akun GitHub kamu.

0.4Pasang aplikasi alat AI

Langkah

Buka freebuff.com/desktop, unduh versi untuk komputermu, lalu pasang seperti aplikasi biasa.

Langkah

Buka opencode.ai/download dan unduh aplikasi desktop untuk komputermu.

Windows

Jalankan file pemasang opencode-desktop-windows-x64.exe yang terunduh.

Mac

Pilih file .dmg sesuai chip: Apple Silicon atau Intel. Cek di menu Apple, lalu About This Mac. Buka file .dmg dan pasang aplikasinya.

Berhasil kalau

Aplikasinya terbuka dan menampilkan layar awal.

Kalau gagal

Muncul peringatan keamanan saat membuka aplikasi? Lihat bagian 8. Kalau tidak bisa jalan sama sekali, ganti alat AI lewat tombol kanan bawah.

1

Aturan dan pengaman

Vibe coding artinya kamu menjelaskan apa yang diinginkan, dan AI yang menulis kodenya. Perananmu adalah pemilik ide dan pemeriksa hasil. Tiga kebiasaan ini menjaga pekerjaanmu tetap aman.

Commit sering

Simpan satu versi setiap kali satu fitur berhasil. Kalau AI merusak sesuatu, kamu bisa kembali ke versi sebelumnya.

Rahasia jangan di repo

Repo kamu publik, siapa saja bisa membacanya. Jangan simpan password, kunci API, atau data pelanggan sungguhan.

Baca yang diubah AI

Lihat file apa saja yang berubah sebelum commit. AI bisa salah, dan kamu yang bertanggung jawab atas hasilnya.

Satu fitur, satu prompt

Minta AI membangun satu bagian, periksa hasilnya, baru lanjut. Prompt yang terlalu besar menghasilkan website yang sulit diperiksa dan sulit diperbaiki.

Pakai usaha yang aman dipublikasikan

Boleh usaha milikmu atau usaha rekaan. Nomor WhatsApp, foto, dan harga yang kamu pakai akan tampil di internet, jadi gunakan data contoh atau data yang memang boleh dilihat umum.

2

Siapkan proyek

Sekitar 10 menit
Tampilan aplikasi bisa sedikit berbeda

Nama tombol dan menu di aplikasi desktop bisa berubah mengikuti versinya. Fasilitator akan menunjukkan layar aslinya, jadi cari tombol yang artinya paling dekat dengan petunjuk di sini.

2.1Buat folder proyek

Langkah

Buka File Explorer dan masuk ke folder Documents. Klik kanan di area kosong, pilih New → Folder, lalu beri nama sesuai di bawah.

Langkah

Buka Finder dan masuk ke folder Documents. Pilih menu File → New Folder, lalu beri nama sesuai di bawah.

Nama folder
[nama-folder]
Berhasil kalau

Ada folder kosong dengan nama itu di Documents.

2.2Buka alat AI dan pilih folder proyek

Langkah

Buka Freebuff Desktop, lalu arahkan aplikasinya ke folder proyek yang baru kamu buat. Folder itu menjadi tempat semua file websitemu.

Model

Pilih model dari daftar model di aplikasi, atau biarkan pilihan bawaan.

Langkah

Buka OpenCode Desktop, lalu buka folder proyek yang baru kamu buat sebagai project. Folder itu menjadi tempat semua file websitemu.

Model

Pilih model yang berlabel free di daftar model aplikasi.

Berhasil kalau

Layar chat terbuka. Ketik halo, AI akan menjawab. Kamu juga bisa mengetik "tampilkan daftar file di folder ini" untuk memastikan AI bekerja di folder yang benar.

3

Rencanakan

Sekitar 40 menit

Bagian ini paling menentukan. Rencana yang jelas menghasilkan website yang jelas, dan rencana yang kabur membuat AI menebak. Tulis rencanamu sendiri sebelum meminta AI mengerjakan apa pun.

3.1Jawab lima pertanyaan

  1. Usaha apa, dan siapa pelanggannya?
  2. Apa yang dicari pelanggan di website?
  3. Satu tindakan utama apa? Misalnya pesan lewat WhatsApp.
  4. Info apa yang harus tampil? Produk, harga, jam buka.
  5. Apa yang belum perlu dibuat? Login, pembayaran, database.
Berhasil kalau

Kamu bisa menjawab kelimanya dengan satu atau dua kalimat, tanpa istilah teknis.

3.2Tulis rencanamu di kotak ini

Langkah

Ganti semua teks di dalam tanda kurung siku dengan isi usahamu. Tulisanmu tersimpan otomatis di browser ini.

Simpan jadi file

Tempel hasil salinan ke chat alat AI dan kirim. Kalimat pembuka yang ikut tersalin meminta AI membuat file RENCANA.md di folder proyek.

Berhasil kalau

AI menyatakan file sudah dibuat, dan RENCANA.md muncul di folder proyek di File Explorer atau Finder.

Lihat contoh isi (usaha fiktif)

Konteks: Saya pemilik Kue Bu Rina, toko kue rumahan. Pelanggan membuka website dari HP.

Tujuan: Website satu halaman agar pelanggan bisa melihat produk dan memesan lewat WhatsApp.

Fitur: (1) Bagian atas: nama toko dan tombol "Pesan via WhatsApp". (2) Daftar 6 produk dengan foto, nama, dan harga. (3) Tombol "Pesan" di tiap produk membuka WhatsApp dengan pesan otomatis. (4) Bagian bawah: alamat dan jam buka.

Batasan: Tampilan HP dulu, warna krem dan cokelat. Tanpa login dan tanpa database. Data produk disimpan di satu file agar mudah diubah.

Cek hasil: Setelah selesai, jelaskan cara membuka website di komputer saya.

3.3Periksa rencanamu

  • Kelima bagian terisi dan tidak ada tanda kurung siku yang tersisa.
  • Fitur ditulis spesifik. "Daftar 6 produk dengan foto, nama, harga" lebih baik daripada "tampilkan produk".
  • Ada satu tindakan utama yang jelas untuk pelanggan.
  • Batasan menyebut apa yang belum dibuat.
Berhasil kalau

Temanmu bisa membaca rencana ini dan menebak website seperti apa yang akan jadi.

4

Bangun dengan AI

Sekitar 60 menit

Polanya berulang: minta rencana, setujui, bangun satu fitur, periksa di browser, perbaiki atau lanjut. Jangan meminta semuanya sekaligus. Tempel setiap prompt di bawah ke chat alat AI.

4.1Minta AI menjelaskan rencananya dulu

Prompt
Baca file RENCANA.md di folder ini. Jelaskan dulu rencanamu dengan bahasa sederhana, jangan ubah file apa pun. Setelah saya setuju, kamu bangun satu fitur pertama saja.
Berhasil kalau

AI menjelaskan rencananya, dan isinya sesuai dengan RENCANA.md. Kalau ada yang meleset, perbaiki rencanamu dan minta AI membuat ulang file RENCANA.md.

4.2Setujui, lalu bangun fitur pertama

Prompt
Saya setuju. Bangun fitur nomor 1 dari RENCANA.md saja. Simpan di index.html di folder utama. Setelah selesai, jelaskan cara membuka hasilnya di komputer saya.
Berhasil kalau

File index.html muncul di folder proyek.

4.3Buka hasilnya di browser

Langkah

Buka folder proyek di File ExplorerFinder dan klik dua kali file index.html. Halamanmu terbuka di browser.

Berhasil kalau

Browser menampilkan halamanmu. Kecilkan lebar jendela untuk melihat tampilan seperti di HP.

4.4Perbaiki dengan prompt kecil dan spesifik

Kurang jelasLebih jelas
Bagus-in dong.Ubah warna tombol jadi hijau dan perbesar tulisan harga.
Kok jelek di HP.Di layar HP, foto produk keluar dari kotak. Buat foto selebar kartu.
Tambah fitur lain.Tambahkan produk ke-7 bernama Brownies dengan harga Rp25.000.
Error!Muncul pesan error ini: [tempel pesan error]. Tolong perbaiki.
Catat

Setelah setiap prompt perbaikan, minta AI mencatatnya. Minimal 3 catatan, karena ini ikut dinilai.

Prompt
Tambahkan catatan ke file PROMPT-LOG.md (buat file jika belum ada). Isinya: prompt perbaikan saya yang terakhir, dan hasilnya (berhasil atau kurang tepat, beserta alasannya).

4.5Ulangi untuk fitur berikutnya

Prompt
Lanjut ke fitur nomor 2 dari RENCANA.md. Jangan ubah fitur yang sudah jadi.
Berhasil kalau

Semua fitur di RENCANA.md sudah tampil di browser dan PROMPT-LOG.md berisi minimal 3 catatan.

5

Simpan ke GitHub

Sekitar 20 menit
Langkah 5.1 sampai 5.4 memakai GitHub Desktop

Kamu cukup mengklik tombol, tanpa mengetik perintah. Nama tombol bisa sedikit berbeda di versi aplikasimu. Setelah itu ada cara opsional memakai prompt AI di langkah 5.5 sampai 5.8.

5.1Tambahkan folder proyek

Langkah

Di GitHub Desktop pilih menu File → Add local repository, lalu pilih folder proyekmu.

Jika muncul pesan

Kalau ada pesan bahwa folder itu belum berupa repository, klik tautan create a repository, lalu klik Create repository.

Berhasil kalau

Daftar file proyekmu muncul di tab Changes, termasuk index.html dan RENCANA.md.

5.2Simpan commit pertama

Langkah

Pastikan semua file di daftar Changes tercentang. Di kotak Summary di kiri bawah, tulis:

versi pertama
Lalu

Klik tombol biru Commit to main. Nama cabangnya bisa saja master, tidak masalah.

Berhasil kalau

Daftar Changes menjadi kosong, dan commit "versi pertama" tampil di tab History.

5.3Publish repository ke GitHub

Langkah

Klik tombol Publish repository di bagian atas. Isi Name dengan [nama-folder].

Penting

Hilangkan centang Keep this code private supaya repo berstatus publik, lalu klik Publish repository.

Berhasil kalau

Alamat github.com/[username GitHub]/[nama-folder] terbuka di browser dan menampilkan semua filemu. Kamu juga bisa memilih menu Repository → View on GitHub.

5.4Tambah README, lalu commit lagi

Prompt ke AI
Buat README.md singkat yang menjelaskan usaha [nama usaha] dan cara membuka website ini.
Lalu

Kembali ke GitHub Desktop. File baru muncul di tab Changes. Tulis tambah README di kotak Summary, klik Commit to main, lalu klik Push origin di bagian atas.

Kebiasaan

Setiap kali satu fitur atau perbaikan selesai, ulangi commit dan Push origin dengan Summary yang berbeda. Minimal 3 commit tercatat sebelum dikumpulkan.

Berhasil kalau

Halaman repo di GitHub menampilkan jumlah commit minimal 3, dan README tampil di bawah daftar file.

Hubungkan alat AI ke GitHub (opsional)

Setelah akun GitHub-mu bisa dipakai alat AI, kamu bisa meminta AI yang menjalankan commit dan push. Hasilnya sama dengan menekan tombol di GitHub Desktop, hanya lebih cepat. Bagian ini hanya berjalan kalau langkah 0.3 dan 5.1 sampai 5.3 sudah selesai, jadi kerjakan yang itu dulu.

Jangan pernah menempelkan password atau token ke chat

Alat AI memakai login GitHub yang sudah ada di komputer, bukan password baru. Kalau AI meminta token, password, atau kunci akses, hentikan dan panggil fasilitator. Jangan pernah menyimpan rahasia semacam itu di dalam file proyek, karena repo kamu publik.

5.5Hubungkan akun GitHub ke alat AI

Langkah

Buka Freebuff, cari menu Integrations (biasanya di pengaturan akun), pilih GitHub, lalu klik Connect. Halaman izin terbuka di browser; masuk dengan akunmu dan setujui akses ke repo yang kamu buat.

Untuk apa

Integrasi ini membuat AI bisa membaca repo, issue, dan pull request. Untuk commit dari komputermu, Freebuff tetap memakai Git yang sudah login lewat GitHub Desktop.

Langkah

OpenCode Desktop memakai login Git di komputermu, jadi tidak ada tombol connect terpisah. Cukup pastikan GitHub Desktop sudah login (langkah 0.3) dan repo sudah ada di GitHub (langkah 5.3).

Lanjutan, tidak wajib

Kalau nanti ingin memakai perintah /oc langsung di issue atau pull request GitHub, jalankan opencode github install di folder proyek lalu ikuti petunjuknya. Ini butuh pengaturan tambahan, jadi lewati dulu kalau belum perlu.

Berhasil kalau

Nama akun GitHub-mu terlihat di alat AI, atau AI bisa menyebut alamat repo proyek ini saat ditanya.

Kalau bingung

Nama menu bisa berbeda di versi lain. Cari kata GitHub atau Integrations di pengaturan aplikasi, atau minta fasilitator menunjukkan layarnya.

5.6Cek sambungan dengan satu prompt

Prompt
Periksa folder kerja ini. Jalankan git status dan git remote -v, lalu jelaskan hasilnya dengan bahasa sederhana. Jangan ubah file apa pun.

Repo GitHub saya seharusnya: https://github.com/[username GitHub]/[nama-folder]
Berhasil kalau

AI menyebut cabang main (atau master) dan alamat repo yang sama dengan repo-mu.

Kalau remote belum ada

Folder proyekmu belum tersambung ke repo. Kirim prompt berikut, lalu cek lagi dengan prompt di atas.

Remote origin belum ada. Tambahkan remote origin dengan alamat https://github.com/[username GitHub]/[nama-folder], lalu tampilkan git remote -v untuk memastikan. Jangan push dulu.

5.7Minta AI commit dan push

Sebelumnya

Buka dulu hasil websitemu di browser dan pastikan perubahannya memang yang kamu mau. AI akan menyimpan semua yang ada di folder, termasuk kesalahan.

Prompt
Commit semua perubahan di folder ini dengan pesan "perbaikan dari AI", lalu push ke branch main. Setelah selesai, tampilkan hasil git log --oneline -3.
Berhasil kalau

Commit baru muncul di tab History GitHub Desktop dan di halaman repo GitHub. Kalau Vercel sudah terpasang, websitemu ikut diperbarui otomatis.

Kebiasaan

Satu fitur selesai, satu commit. Tulis pesan commit yang jelas, misalnya "tambah tombol WhatsApp", supaya riwayatmu mudah dibaca penilai.

Catat

Setiap kali AI yang melakukan push, tambahkan satu baris ke PROMPT-LOG.md lewat prompt yang sama seperti di langkah 4.4.

5.8Kalau AI tidak bisa push

Prompt
Push gagal dengan pesan ini: [tempel pesan error apa adanya]. Jelaskan penyebabnya dengan bahasa sederhana, lalu sebutkan tombol yang harus saya klik di GitHub Desktop. Jangan meminta atau menyimpan token dan password.
  • Authentication failed berarti login Git di komputermu kedaluwarsa. Buka GitHub Desktop, masuk lagi lewat File → Options → Accounts, lalu push dari sana.
  • Repository not found berarti alamat repo salah atau belum dibuat. Bandingkan dengan alamat di halaman repo GitHub-mu.
  • Permission denied berarti repo itu bukan milik akun yang sedang login.
  • Rejected berarti isi repo berubah di GitHub. Minta AI menjalankan git pull --rebase, periksa hasilnya, baru push lagi.
Batas aman

Kalau AI tetap gagal setelah dua kali mencoba, kembali ke GitHub Desktop dan kerjakan lewat tombol. Cara itu selalu cukup untuk mengumpulkan tugas.

Deploy ke Vercel

Sekitar 15 menit

6.1Mulai project baru

Langkah

Masuk ke vercel.com dengan akun GitHub, klik Add New, lalu pilih Project.

6.2Impor repo kamu

Langkah

Cari repo [nama-folder] di daftar dan klik Import.

Kalau gagal

Repo tidak muncul: klik Adjust GitHub App Permissions, izinkan akses ke repo itu, lalu kembali.

6.3Deploy

Langkah

Biarkan semua pengaturan bawaan dan klik Deploy. Tunggu sampai prosesnya selesai.

Berhasil kalau

Muncul halaman keberhasilan dengan tampilan websitemu dan alamat berakhiran .vercel.app.

6.4Cek di HP dan simpan linknya

Langkah

Setelahnya

Setiap kali kamu menekan Push origin di GitHub Desktop, Vercel memperbarui website secara otomatis.

8

Jika tersangkut

Kalau AI memberi pesan error atau hasilnya salah, salin pesannya persis seperti yang tertulis dan tempel ke AI, itu petunjuk terbaik baginya. Kalau masih buntu lebih dari 10 menit, angkat tangan dan panggil fasilitator.

"Windows protected your PC" saat membuka pemasang

Ini peringatan standar Windows untuk aplikasi baru. Kalau pemasang itu kamu unduh dari situs resmi yang disebut di panduan, klik More info, lalu Run anyway.

Aplikasi "tidak bisa dibuka karena dari developer yang tidak dikenal" (Mac)

Kalau aplikasi itu kamu unduh dari situs resmi yang disebut di panduan, klik kanan ikon aplikasinya di folder Applications, pilih Open, lalu klik Open sekali lagi.

Aplikasi alat AI tidak mau terbuka atau tidak bisa dipakai

Tutup aplikasinya dan buka lagi. Kalau masih gagal, panggil fasilitator. Cadangannya, ganti ke OpenCode DesktopFreebuff Desktop lewat tombol kanan bawah dan pasang yang itu.

AI tidak melihat file di folder proyekku

Pastikan folder proyek sudah dipilih di aplikasi alat AI, bukan folder lain. Lalu minta AI memeriksanya:

Tampilkan daftar file di folder kerja kamu sekarang.
Tombol Commit di GitHub Desktop tidak bisa diklik

Pastikan kotak Summary sudah terisi dan minimal satu file di daftar Changes tercentang.

Tombol Push origin tidak muncul, atau yang ada hanya Publish repository

Repo kamu belum dipublikasikan. Klik Publish repository dulu (langkah 5.3). Setelah itu, tombol Push origin muncul tiap ada commit baru.

Repo terlanjur berstatus private

Buka repo di github.com, pilih Settings, gulir ke bagian Danger Zone, klik Change visibility, lalu pilih public.

Repo tidak muncul di Vercel

Di halaman Import klik Adjust GitHub App Permissions, izinkan akses ke repo kamu, lalu muat ulang halaman.

Website di Vercel menampilkan 404

Biasanya file halamanmu bukan bernama index.html atau tidak berada di folder utama. Minta AI memindahkannya, lalu commit dan Push origin lagi di GitHub Desktop.

Pindahkan halaman website ke index.html di folder utama.
AI merusak hasil yang tadinya sudah bagus

Di GitHub Desktop, buka tab Changes, klik kanan salah satu file yang berubah, lalu pilih Discard Changes (atau Discard All Changes untuk semuanya). Ini mengembalikan file ke commit terakhir dan membuang perubahan yang belum di-commit, jadi pastikan kamu memang ingin membatalkannya.

Karena itu kamu perlu commit setiap kali satu fitur berhasil.

Tampilan di HP berantakan
Di layar HP lebar 400px, bagian [sebutkan bagian yang rusak] keluar dari layar. Perbaiki agar rapi di HP tanpa mengubah bagian lain.
Menunya bernama "Integrations" tidak ketemu

Nama menu bisa berbeda antar versi. Cari kata GitHub di halaman pengaturan akun alat AI-mu. Kalau tetap tidak ada, lewati saja: commit lewat GitHub Desktop sudah cukup untuk tugas ini.

AI bilang tidak punya izin ke GitHub

Artinya login Git di komputer belum aktif atau repo belum tersambung. Kerjakan langkah 5.5 dan 5.6, lalu coba lagi. Jangan pernah menjawab permintaan token dari AI dengan menempelkan token asli.
