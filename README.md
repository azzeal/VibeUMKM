# VibeUMKM

Panduan Lab Vibe Coding UMKM — single-file static handbook page.

## Files

- `index.html` — the whole handbook (inline CSS/JS, no build step)

## Run locally

Just open `index.html` in a browser, or serve it:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080

## Publish

Enable **Settings → Pages → Deploy from branch → `main` / root** to serve the page at
`https://azzeal.github.io/VibeUMKM/`.
