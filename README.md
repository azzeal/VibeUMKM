# VibeUMKM

Kumpulan panduan lab (single-file HTML, tanpa build step).

## Files

- `index.html` — Panduan Lab Vibe Coding UMKM (website satu halaman untuk UMKM)
- `tanstack-ekraf.html` — Panduan Lab TanStack EKRAF (revamp · fix · secure dashboard admin TanStack Start)

## Run locally

Open the file in a browser, or serve the folder:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080 (and http://localhost:8080/tanstack-ekraf.html)

## Publish

Enable **Settings → Pages → Deploy from branch → `main` / root** to serve the pages at
`https://azzeal.github.io/VibeUMKM/` and `https://azzeal.github.io/VibeUMKM/tanstack-ekraf.html`.
